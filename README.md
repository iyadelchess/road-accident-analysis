# Analyse des accidents de la route en France

Projet d'analyse de données portant sur les accidents corporels de la circulation en France.

L'objectif est d'explorer les données, d'identifier des relations entre différents facteurs et d'analyser les corrélations afin de mettre en évidence les risques d'interprétations trompeuses.

## Source des données

Les données utilisées proviennent de la base BAAC (*Bulletin d'Analyse des Accidents Corporels de la Circulation*), publiée sur **data.gouv.fr** par le Ministère de l'Intérieur.

Les données comprennent notamment des informations sur les accidents, les lieux, les véhicules et les usagers.
